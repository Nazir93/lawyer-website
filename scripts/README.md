# Скрипты для настройки сервера

## 📋 Описание

Этот каталог содержит скрипты для автоматизации настройки и диагностики сервера.

## 🚀 Скрипты

### `create-admin.js` - Создание администратора

Создает администраторскую учетную запись в базе данных.

**Использование:**
```bash
node scripts/create-admin.js
```

---

### `reset-admin-password.js` - Сброс пароля администратора

Сбрасывает пароль администратора.

**Использование:**
```bash
node scripts/reset-admin-password.js
```

---

## 📝 Установка на сервер

### Копирование файлов

```bash
# На вашем компьютере
scp -r scripts/ root@ВАШ_IP:/var/www/lawyer-website/

# На сервере
cd /var/www/lawyer-website
```

---

## 🔧 Зависимости

Скрипты используют Node.js и Prisma для работы с базой данных.

---

## ⚠️ Важные замечания

1. **Права доступа**: Убедитесь, что у вас есть доступ к базе данных.
2. **Переменные окружения**: Убедитесь, что файл `.env.local` настроен правильно.
